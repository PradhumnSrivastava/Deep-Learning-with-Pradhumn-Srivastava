# When Should You Use Machine Learning?

Choose ML when:

- Dataset is small
- Features are meaningful and interpretable
- Fast training is needed
- Computational resources are limited
- Explainability is important

---

# When Should You Use Deep Learning?

Choose DL when:

- Dataset is very large
- Data is images, audio, text, or video
- Highest accuracy is desired
- GPUs are available
- Automatic feature extraction is beneficial

# Key Takeaways

- Deep Learning is **not separate** from Machine Learning; it is a specialized subset.
- The main distinction is **automatic representation learning**. ML often depends on human-crafted features, while DL learns hierarchical features directly from data.
- Deep Learning generally excels on large-scale, unstructured data (images, text, audio), whereas classical ML is often the better choice for smaller, structured datasets.

---

# Interview Questions

### Is Deep Learning different from Machine Learning?

Yes. Deep Learning is a subset of Machine Learning that uses deep neural networks to learn features automatically.

---

### Which requires feature engineering?

Machine Learning generally requires manual feature engineering, while Deep Learning learns features automatically.

---

### Which performs better on images?

Deep Learning, especially architectures such as CNNs and Transformers.

---

### Which is more interpretable?

Machine Learning models are typically more interpretable than deep neural networks.
